## How to swap in a real photo (quick reference)

**Phone slides (PHONE-1/2/3):**
In `illustrations.js`, replace the entire `svg: \`...\`` string in the relevant `phoneSlides[]` entry with:
```js
svg: `<img src="screenshot-customer.webp" alt="Customer ordering screen" style="width:100%;height:100%;object-fit:cover">`
```

**HOW step images (HOW-1 through HOW-4):**
```html
<!-- BEFORE (placeholder): -->
<div class="step-img" id="how-img-1" data-asset-id="HOW-1">
  <div class="step-img-placeholder" aria-hidden="true">...</div>
</div>

<!-- AFTER (real photo): -->
<div class="step-img" id="how-img-1" data-asset-id="HOW-1">
  <img src="step-1.webp" alt="Pelanggan duduk di meja" loading="lazy">
</div>
```
(Remove the `.step-img-placeholder` div when the real `<img>` is in place.)

**Founder photos (FND-1/2):**
The `.founder-photo` div uses CSS `display:grid;place-items:center`. Add the photo inside it and add a CSS rule:
```css
.founder-photo img { width:100%; height:100%; object-fit:cover; border-radius:50%; }
```
```html
<div class="founder-photo">
  <img src="founder1.webp" alt="[Founder 1 Name]">
</div>
```

**Favicon + OG meta (add to `<head>` in index.html):**
```html
<link rel="icon" href="favicon.ico" sizes="any">
<link rel="icon" href="favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="apple-touch-icon.png">
<meta property="og:title" content="TymiY — Sistem QR Order untuk Kafé & Resto Kecil">
<meta property="og:description" content="TymiY: sistem order lewat QR langsung dari meja. Setup gratis, harga terjangkau.">
<meta property="og:image" content="https://yourdomain.com/og-image.png">
<meta property="og:url" content="https://yourdomain.com/">
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:image" content="https://yourdomain.com/og-image.png">
```
